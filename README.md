# ОлеговщинаСМС

Self-hosted мессенджер для одного владельца: сквозное шифрование личных сообщений, лента постов,
модерация, игры «Арена» (3D-шутер) и «Танки» (онлайн-бои на танках).
Сервер — одна программа на Go без зависимостей, клиент открывается в браузере.

Подробная инструкция для пользователя — в [ИНСТРУКЦИЯ.txt](ИНСТРУКЦИЯ.txt).

## Сборка

Нужен Go 1.22+ и Python 3.

```
python3 build.py          # собирает web/*.html из src/
go test .                 # тесты
go build -o olegovshchina .
```

`web/` — собранные страницы, которые встраиваются в программу. Править нужно `src/`, затем запускать `build.py`.

## Запуск на VPS за Caddy

```
./olegovshchina -http -port 8080 -admin ВАШ_ID
```

Данные сервера лежат в `shepot-data/` рядом с программой. Эта папка не хранится в репозитории:
в ней ключи, аккаунты и сообщения.

## Структура

| Файл | Что внутри |
|---|---|
| `main.go` | HTTP-сервер, аккаунты, сообщения, события |
| `feed.go`, `mod.go`, `nick.go` | лента, модерация, никнеймы |
| `game.go`, `gamemaps.go` | «Арена» |
| `tanks.go`, `tankmodes.go` | «Танки»: бой, флаги, точки, ящики, мины, припасы |
| `tankdata.go`, `tankprof.go`, `tankmaps.go` | характеристики техники, профили и выдача админом, карты |
| `src/` | клиент: мессенджер (`app.js`), игры (`game.js`, `tanks.js`) |
